# ApexGPT v1.0.0: MVP docs (archive)

These are the documents that planned and tracked the **ApexGPT MVP**, from the first plan on 2026-11-12 to the release of [**v1.0.0**](https://github.com/RChaubey16/apexgpt/releases/tag/v1.0.0) on 2026-11-26. They're frozen as they were at that release and are **not updated** any more. For where the project stands now, see the [current docs](../../).

| File | What it was |
|---|---|
| [MVP-PLAN.md](./MVP-PLAN.md) | The MVP plan: key decisions, the 8 phases (0 to 7) with their features, branches and commit messages, the development workflow and the timeline |
| [PROGRESS.md](./PROGRESS.md) | The MVP's progress tracker: feature checklists for every phase, the **Decision Log** (why each choice was made), the day-by-day **Session Log**, and the Known Issues as they stood at the release |
| [FEATURES.md](./FEATURES.md) | The feature plan as written before the build. Tier 1 was the MVP |

**Useful for:**
- **Why something is the way it is:** search the Decision Log in `PROGRESS.md`. Code comments that cite "the Decision Log" or a feature id like F3.1 point here.
- **How a feature was built and measured:** search its id (e.g. `F6.4`) in the Session Log.
- **What the MVP covered:** the phases in `MVP-PLAN.md`.

The Known Issues still open at the release were carried over into the current [PROGRESS.md](../../PROGRESS.md).
